## 行为

- 评分、观看历史、播放进度、季度资料与季度完成状态共用 Trakt 只读 GET 重试。
- 每个读取最多尝试 3 次，重试等待 1 秒和 2 秒，仍使用原有每次请求超时及系统代理配置。
- 无响应、暂时连接/代理/超时/传输异常、HTTP 502/503/504 可重试。
- HTTP 401/403/404/429、重定向、TLS 错误及其他非暂时请求错误不自动重试；保留现有 OAuth 401 处理路径。
- 空数组是合法结果；无效 JSON/结构和耗尽重试仍返回来源失败，不伪装成没有数据。
- 只读 GET 禁止跟随重定向，完整缓冲后关闭响应连接。
- 插件诊断仅输出固定传输分类、状态码及尝试次数；不输出异常原文、响应正文、访问令牌或请求头。
- 不将 GET 重试套用于 OAuth POST、豆瓣写入或其他平台请求。
