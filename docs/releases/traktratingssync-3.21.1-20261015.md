# TraktRatingsSync 3.21.1：观察陈旧不再等同登录失效

## 状态与授权

2026-10-15 用户确认调整消费者行为：浏览器未持续观察不直接阻断，网站登录有效则继续同步；
失效、身份不符、鉴权失败、验证码与限流仍阻断。本次只完成本地实现、离线测试和豆瓣只读验收，
**没有提交、推送、安装插件、保存生产配置、重启或触发同步**。生产仍是 3.21.0。

此前现场检查确认：每日 10:00 的任务实际执行，但 10 月 11–15 日因 `ass_cookie_expired` 暂停。
豆瓣与网易云的观察时间分别停在北京时间 10 月 11 日 02:28、00:38，检查时已超过 109 小时；
`ass_max_age=3600`。ASS 认证读取正常，必需 Cookie 的 expirationDate 未到，不是调度或 Read Key 故障。

## 行为变化

- 保留 `ass_max_age` 字段、默认 3600 秒及原配置值，改为**提示阈值**，不是随意增大安全期限。
- 观察年龄超阈值仅在每轮每站首次日志和详情页提示，不计为来源失败，不发送 Cookie 失效通知。
  新观察读取成功后清除提示；页面显示上次检查时间，不将历史提示当作实时网站认证状态。
- 每次仍执行 ASS access-status → metadata → value → metadata，固定 Key、租户、条目、版本与消费范围。
  不缓存、不回退、不重标快照；invalid、必需 Cookie 到期/缺失、未来时钟异常、身份或版本变化仍阻断。
- 豆瓣 ASS 模式复用原首页 GET，同时检查 HTTP 200、登录态和 CSRF。
  当前页面以全局账号导航中的 HTTPS 豆瓣站内退出控件确认登录；旧 `_USER_ID` 若存在，必须与 dbcl2 标识一致。
  正文中的退出/个人主页链接、外站链接和单独的 ck 都不能放行。
- 导航只证明登录，不是数字账号独立核对。ASS 条目绑定与旧版账号冲突检查仍保留。
- 网络异常、5xx、无法识别登录标记或缺少 CSRF 只停本轮，保留 pending 并允许下次定时检查。
  明确匿名/拒绝访问、验证码及限流继续原暂停/冷却流程；不自动解除已有人工暂停。
- 网易云沿用账号接口检查；不修改 CSRF 作用域、业务额度、来源范围、调度、数据库或采集扩展。

## 豆瓣网站只读验收

在生产容器独立短生命周期进程内，经 stdin 加载候选 helper；没有替换运行文件或初始化主插件，
没有访问插件状态数据库。凭据只在进程内读取，日志静默，输出仅固定分类和布尔摘要。

- 共 4 次有界只读首页检查；每次重新完整授权读取 ASS。网站响应上限 2 MiB、整体期限 20 秒，
  TLS 校验、禁止重定向、独立 Session、不继承环境代理；不发送收藏、评分等写入请求。
- 首次候选只支持 `_USER_ID`，真实页面没有此标记，正确拒绝但不满足可用性。
  后续只读结构检查确认真实页面有全局账号导航的站内退出控件，故补齐该识别方式及反例测试；
  没有把获得 ck 直接当成已登录。
- 最终候选检查：ASS 成功，观察年龄约 **394269 秒（109.5 小时）**，豆瓣 HTTP 200，
  登录态确认、CSRF 格式有效，无验证码/限流或临时检查失败。
- 证明**当前豆瓣 Cookie 实际仍可登录**，并且候选适配真实页面；不代表已部署、已恢复生产同步、
  已完成业务写入，或已独立核对目标数字账号。本轮没有网易云网站验收。
